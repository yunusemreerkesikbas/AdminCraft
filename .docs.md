# AdminCraft - Local Development Setup

## 🚀 Quick Start

### Prerequisites
- Java 21
- Maven 3.9+
- Docker & Docker Compose
- Git

## 📋 Local Development Commands

### 1. Database Setup (Docker)

```bash
# Start all services
docker-compose up -d

# Start only MySQL database
docker-compose up -d mysql-db

# Start MySQL + phpMyAdmin
docker-compose up -d mysql-db phpmyadmin

# Stop all services
docker-compose down

# Reset database (delete all data)
docker-compose down
docker volume rm admincraft_mysql_data admincraft_mysql_dev_data
docker-compose up -d mysql-db
```

### 2. Spring Boot Application

**IMPORTANT**: All Spring Boot commands must be run from the `backend/` directory.

```bash
# Navigate to backend directory first
cd backend

# For PowerShell (Windows) - use quotes for -D parameters:
mvn spring-boot:run "-Dspring.profiles.active=dev"
mvn spring-boot:run "-Dspring.profiles.active=docker" 
mvn spring-boot:run "-Dspring.profiles.active=prod"

# Alternative syntax (works in all terminals):
mvn spring-boot:run -Dspring.profiles.active=dev
mvn spring-boot:run -Dspring.profiles.active=docker
mvn spring-boot:run -Dspring.profiles.active=prod

# Build project
mvn clean compile

# Run tests
mvn test

# Package as JAR
mvn package
```

### 3. Database Connection Commands

#### Direct MySQL Connection (via Docker)
```bash
# Connect to main database
docker exec -it admincraft-mysql mysql -u root -p1234 admincraft_db

# Connect to development database
docker exec -it admincraft-mysql mysql -u root -p1234 admincraft_dev

# Show all databases
docker exec admincraft-mysql mysql -u root -p1234 -e "SHOW DATABASES;"

# Show tables in main database
docker exec admincraft-mysql mysql -u root -p1234 admincraft_db -e "SHOW TABLES;"

# Show tables in dev database
docker exec admincraft-mysql mysql -u root -p1234 admincraft_dev -e "SHOW TABLES;"

# Execute custom SQL
docker exec admincraft-mysql mysql -u root -p1234 admincraft_db -e "SELECT * FROM tenants;"
```

#### MySQL Workbench Connection
- **Host**: `localhost`
- **Port**: `3308` (main) / `3307` (dev)
- **Username**: `root`
- **Password**: `1234`
- **Schema**: `admincraft_db` / `admincraft_dev`

## 🗂️ Database Schema

### Current Tables
```sql
-- Core entities
tenants         -- Multi-tenant data
users           -- User management
contents        -- CMS content
content_types   -- Content type definitions
media_files     -- File uploads
menus           -- Navigation menus
sites           -- Site configuration
```

### Database Profiles
- **dev**: Uses `admincraft_dev` database with `create-drop` (recreates on restart)
- **docker**: Uses `admincraft_db` database with `update` (preserves data)
- **prod**: Uses `admincraft_prod` database with `validate` (no schema changes)

## 🔧 Configuration

### Environment Variables
```bash
# Database Configuration
DB_HOST=mysql-db              # Docker container name
DB_PORT=3306                  # Internal port
DB_NAME=admincraft_db         # Database name
DB_USERNAME=root              # Database user
DB_PASSWORD=1234              # Database password

# Application Configuration
SPRING_PROFILES_ACTIVE=dev    # Active profile
SERVER_PORT=8080              # Application port
```

### Application Profiles

#### Development Profile (`dev`)
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/admincraft_dev
    username: root
    password: 1234
  jpa:
    hibernate:
      ddl-auto: create-drop    # Recreates tables on restart
    show-sql: true            # Shows SQL queries
```

#### Docker Profile (`docker`)
```yaml
spring:
  datasource:
    url: jdbc:mysql://mysql-db:3306/admincraft_db
    username: root
    password: 1234
  jpa:
    hibernate:
      ddl-auto: update        # Updates schema only
    show-sql: false
```

## 🐛 Troubleshooting

### Common Issues

#### 1. Database Connection Failed
```bash
# Check if MySQL container is running
docker ps --filter name=admincraft-mysql

# Check MySQL logs
docker logs admincraft-mysql --tail=20

# Reset MySQL container
docker-compose down
docker volume rm admincraft_mysql_data
docker-compose up -d mysql-db
```

#### 2. Application Won't Start
```bash
# Navigate to backend directory first
cd backend

# Check if port 8080 is available
netstat -an | findstr :8080

# Use different port
mvn spring-boot:run -Dserver.port=8090

# Check application logs for errors
mvn spring-boot:run -Dspring.profiles.active=dev
```

#### 3. Tables Not Created
```bash
# Navigate to backend directory first
cd backend

# Verify profile is correct
mvn spring-boot:run -Dspring.profiles.active=dev

# Check database exists
docker exec admincraft-mysql mysql -u root -p1234 -e "SHOW DATABASES;"

# Force recreate with dev profile (drops existing tables)
# Stop app, start with dev profile
```

#### 4. Docker Issues
```bash
# Check Docker status
docker --version
docker-compose --version

# Restart Docker services
docker-compose restart

# View all container logs
docker-compose logs

# Check specific service
docker-compose logs mysql-db
docker-compose logs admincraft-backend
```

### Performance Tips

#### 1. Faster Startup
```bash
# Navigate to backend directory first
cd backend

# Skip tests during development
mvn spring-boot:run -Dspring.profiles.active=dev -DskipTests

# Use dev profile for faster database operations
mvn spring-boot:run -Dspring.profiles.active=dev
```

#### 2. Database Optimization
```bash
# Navigate to backend directory first
cd backend

# Connect to main database for persistence
mvn spring-boot:run -Dspring.profiles.active=docker

# Use dev database for testing (auto-cleanup)
mvn spring-boot:run -Dspring.profiles.active=dev
```

## 🔄 Development Workflow

### Daily Development
1. Start database: `docker-compose up -d mysql-db`
2. Navigate to backend: `cd backend`
3. Run application: `mvn spring-boot:run -Dspring.profiles.active=dev`
4. Access phpMyAdmin: http://localhost:8081
5. Test API: http://localhost:8080/api/actuator/health

### Feature Development
1. Create feature branch: `git checkout -b feature/new-feature`
2. Navigate to backend directory: `cd backend`
3. Use dev profile for rapid iteration
4. Test with Docker profile before commit
5. Commit and push changes

### Database Changes
1. Navigate to backend directory: `cd backend`
2. Modify entities in `src/main/java/com/backend/domain/entity/`
3. Restart application (dev profile auto-recreates tables)
4. Verify changes in phpMyAdmin
5. Test with sample data
