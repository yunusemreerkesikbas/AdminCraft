# ItemDialog - Reusable CRUD Dialog Component

## 📋 Overview

Schema-driven dialog component for Create/Edit operations with multi-language tabs (General + TR/EN).

## 🚀 Quick Start

```typescript
import { ItemDialogService } from '@shared/services/item-dialog.service';

export class MyListComponent {
  #dialogService = inject(ItemDialogService);
  #myService = inject(MyService);
  #notification = inject(NotificationService);

  create(): void {
    const options: ItemDialogOptions<MyDto> = {
      mode: 'create',
      titleKey: 'admin.myModule.entityName',
      schema: this.#buildSchema(),
      languages: ['tr', 'en'],
      initial: {
        status: 'DRAFT',
        tr: { title: '', description: '' },
        en: { title: '', description: '' }
      }
    };

    this.#dialogService.open<MyDto>(options)
      .pipe(take(1))
      .subscribe((result) => {
        if (!result) return;
        this.#myService.create(result).pipe(take(1)).subscribe(() => {
          this.#notification.success('admin.messages.createSuccess');
          this.#loadData();
        });
      });
  }

  #buildSchema(): ItemDialogSchema {
    return {
      general: [
        {
          key: 'status',
          type: 'select',
          labelKey: 'admin.fields.status',
          required: true,
          options: [
            { value: 'ACTIVE', labelKey: 'admin.status.active' }
          ]
        }
      ],
      i18n: [
        {
          key: 'title',
          type: 'text',
          labelKey: 'admin.fields.title',
          required: true,
          maxLength: 200
        }
      ]
    };
  }
}
```

## 📝 Field Types

| Type | Usage |
|------|-------|
| `text` | Single-line input |
| `textarea` | Multi-line input |
| `select` | Dropdown with options |
| `number` | Numeric input |
| `checkbox` | Boolean toggle |

## 🎯 API

**ItemDialogOptions:**

```typescript
{
  mode: 'create' | 'edit';
  titleKey: string;              // i18n key
  schema: ItemDialogSchema;
  languages: ['tr', 'en'];
  initial?: Partial<TDto>;
  id?: TId;                      // For edit mode
  modalData?: {
    width?: string;              // Default: '720px'
    disableClose?: boolean;      // Default: true
  }
}
```

**Return Value:**

```typescript
{
  // General fields
  status: 'ACTIVE',
  
  // Language fields
  tr: { title: 'Başlık' },
  en: { title: 'Title' }
}
```

## ✅ Best Practices

- Always use `.pipe(take(1))` to prevent memory leaks
- Provide initial values for all schema fields
- Use strong typing: `open<MyDto, number>(options)`
- Private methods with `#` prefix

## 🌐 Required i18n Keys

# AdminCraft - Sprint: Multi‑Language Page Builder (Backend) Referansı

Bu doküman, frontend implementasyonu için gerekli backend yapısını ve endpoint’leri özetler.

## Yapı (Özet)

- Multi-tenant: Tenant kimliği istekten türetilir (`X-Tenant-ID` veya JWT). İstemciden `tenantId` alınmaz.
- UID/UUID: Her kayıt `uuid` ve "cmsitem_xxxxxxxx" formatlı `uid` içerir.
- i18n model: `pages` (dil-agnostik) + `page_i18n` (dil‑özgü alanlar).
- HTML güvenliği: `descriptionHtml` sunucu tarafında sanitize edilir.

## Endpoint’ler

### Pages

- POST `/api/pages`
  - Body: `{ categoryId?, status?, featuredImage?, styleClasses?, isHome?, sortOrder? }`
  - Response: `PageResponse` (id, uuid, uid, tenantId, status, isHome, sortOrder ...)

- GET `/api/pages/{id}`
  - Headers: `X-Tenant-ID`
  - Response: `PageResponse`

- GET `/api/pages/{id}/with-i18n`
  - Headers: `X-Tenant-ID`
  - Response: `{ page: PageResponse, translations: { tr|en: PageI18nResponse } }`

- PUT `/api/pages/{id}`
  - Headers: `X-Tenant-ID`
  - Body: `{ categoryId?, status?, featuredImage?, styleClasses?, isHome?, sortOrder? }`
  - Response: `PageResponse`

- DELETE `/api/pages/{id}`
  - Headers: `X-Tenant-ID`
  - Response: `ApiResponse<void>`

- PUT `/api/pages/{id}/set-home`
  - Headers: `X-Tenant-ID`
  - Response: `PageResponse`

### Page i18n

- GET `/api/pages/{pageId}/i18n/{language}`
  - Headers: `X-Tenant-ID`
  - Response: `PageI18nResponse`

- PUT `/api/pages/{pageId}/i18n/{language}`
  - Headers: `X-Tenant-ID`
  - Body: `{ urlPath?, title?, subtitle?, metaTitle?, metaDescription?, description?, descriptionHtml?, status?, scheduledAt? }`
  - Response: `PageI18nResponse`

- POST `/api/pages/{pageId}/publish/{language}`
  - Headers: `X-Tenant-ID`
  - Body: `{ scheduledAt?: string }` (yoksa hemen yayın)
  - Response: `PageI18nResponse`

### Tenant Languages

- GET `/api/tenants/{tenantId}/languages`
- PUT `/api/tenants/{tenantId}/languages`
  - Body: `{ defaultLanguage: 'TR'|'EN', supportedLanguages: ['TR'|'EN', ...] }`
- POST `/api/tenants/{tenantId}/languages/provision`
  - Body: `{ languages: ['TR'|'EN', ...] }`

### Provisioning Jobs

- GET `/api/provisioning/jobs/{jobUuid}` → `ProvisioningJobResponse`

## Frontend Servis Sözleşmesi (Örnek)

```ts
// Pages
GET   /api/pages/:id
GET   /api/pages/:id/with-i18n
POST  /api/pages
PUT   /api/pages/:id

PUT   /api/pages/:id/set-home

// Page i18n
GET  /api/pages/:pageId/i18n/:lang
PUT  /api/pages/:pageId/i18n/:lang
POST /api/pages/:pageId/publish/:lang

// Tenant languages
GET  /api/tenants/:tenantId/languages
PUT  /api/tenants/:tenantId/languages
POST /api/tenants/:tenantId/languages/provision
```

## Notlar

- Tüm admin endpoint’leri `isAuthenticated()` şartına tabi.
- `X-Tenant-ID` header’ı zorunlu kabul edilerek backend’de doğrulanır.
- `descriptionHtml` güvenli whitelist ile sanitize edilir.
