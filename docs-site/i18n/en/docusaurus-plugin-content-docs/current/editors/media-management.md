# Media Management

Media Library helps you keep images and files organized inside Craftive. Good media management affects page quality, accessibility, and SEO.

## Uploading media

Think about the purpose of the file before uploading it. An image may be used in a hero, card, gallery, or logo context.

After upload, complete:

- Clear name or title.
- Alternative text.
- Description when useful.
- Relevant tags.
- Language-specific text.

## Responsive media

Some areas work better with separate desktop and mobile images. Wide hero images are especially worth checking on mobile.

## Using media in components

Choose media according to the component purpose:

- If one image represents the whole component, select it at component level.
- If each card needs a different image, select media at entry level.
- For logos and icons, use simple, sharp, high-contrast files.

## Good practices

- Use high-quality files that are not unnecessarily large.
- Add alternative text for every meaningful image.
- Avoid uploading many near-duplicate versions of the same image.
- Check mobile preview before publishing.
