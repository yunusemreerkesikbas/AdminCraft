# Page Builder Usage

Page Builder helps you create pages from prepared structures. The goal is to manage new pages and content blocks without breaking the design.

## Page creation model

A page usually contains:

- **Template:** The general page skeleton.
- **Slot:** Placement regions inside the page.
- **Component:** A content block visitors can see.
- **Entry:** Repeated cards or rows inside a component.

## Typical workflow

<ol className="doc-flow">
  <li>Create a new page or open an existing one.</li>
  <li>Choose a template that matches the page goal.</li>
  <li>Review the slots provided by the template.</li>
  <li>Add the needed components to the right slots.</li>
  <li>Edit component copy, media choices, and order.</li>
  <li>Preview the page.</li>
  <li>Complete the checklist before publishing.</li>
</ol>

## Component or entry?

| Need | Use | Why |
| --- | --- | --- |
| Create a separate page section | Component | It has its own title, media, and rendering behavior. |
| Repeat cards inside the same section | Entry | Ordering and repeated content are easier to manage. |
| Add one image or CTA area | Component | The purpose and design behavior are clearer. |
| Manage list, gallery, or FAQ rows | Entry | Content rows repeat inside the same structure. |

## Good practices

<ul className="doc-checklist">
  <li>Give every page one clear goal.</li>
  <li>Keep hero copy short and direct.</li>
  <li>Review entry count in long lists.</li>
  <li>Add meaningful alternative text for every image.</li>
  <li>Remove empty or incomplete components before publishing.</li>
</ul>
