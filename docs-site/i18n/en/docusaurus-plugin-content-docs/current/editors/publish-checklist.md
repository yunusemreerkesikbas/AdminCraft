# Publish Checklist

Use this checklist before publishing. The goal is to avoid showing incomplete or incorrect content to visitors.

## Content check

- Titles are clear and match the page goal.
- No placeholder copy remains.
- Language variations have been reviewed.
- CTA copy is understandable.
- Long text remains readable on mobile.

## Media check

- Main images are correct.
- Mobile view has been reviewed.
- Alternative text is complete.
- No broken or missing media remains.

## Page structure check

- Component order is correct.
- No empty slot or empty component is visible.
- Repeated entries are in the expected order.
- Unneeded draft content has been cleaned up.

## Final check

- The page has been reviewed in SmartEdit or preview.
- Desktop and mobile views have been checked.
- The language being published is correct.
- The scope of the change is clear to the team.
