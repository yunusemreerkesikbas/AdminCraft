# SmartEdit Usage

SmartEdit lets you edit a page in a context close to the real visitor view. This makes it easier to understand which copy or image you are changing.

## When to use it

- When making small copy edits on a published page.
- When checking component content in page context.
- When previewing changes before publishing.
- When understanding which component controls which area.

## Typical workflow

1. Open the page you want to edit.
2. View it in SmartEdit.
3. Select the component you want to change.
4. Update copy, media, or entry fields.
5. Preview the change.
6. Discard it or prepare it for publishing.
7. Review the change summary before publishing.

## Things to watch

- Draft changes in SmartEdit may not affect the live visitor experience until they are published.
- The preview session is valid for a limited time; if it expires, you may need to renew the SmartEdit session.
- Preview links belong to the admin workspace and should not be used as visitor sharing links.
- If a component is reused across pages, check the scope of your change.
- If you are editing language-specific content, make sure the correct language is selected.
- When changing images, review the mobile view as well.
