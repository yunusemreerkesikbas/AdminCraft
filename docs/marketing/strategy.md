# Craftive — Strategy Document

> Last updated: 2026-03-24

## 1. Core Vision

Craftive is a platform for **modular project solutions tailored to customer needs**.

The goal is not to build a brand-new system from scratch for every project. The goal is to deliver the right solution faster by combining a shared multi-tenant foundation, reusable modules, and controlled customization.

Core approach:

- reuse a shared platform instead of rebuilding from zero
- turn repeated needs into reusable modules instead of one-off custom code
- keep post-launch maintenance and expansion manageable

## 2. Best-Fit Customers

Craftive is not a one-size-fits-all product for every possible customer.

The strongest fit today is:

- companies that need a corporate website, content platform, or catalog foundation
- agencies that want to deliver client projects on a reusable operational base
- teams that need tenant isolation, structured content operations, and headless delivery

This does not mean Craftive is limited to only these profiles. It means these are the customer types where the current platform is easiest to position, easiest to prove, and most commercially credible.

Typical decision-makers:

- founders or business owners
- agency owners or operations leads
- digital project owners
- technical decision-makers

## 3. What We Sell

Craftive does not sell a fixed package product.

It sells:

- the platform foundation
- the right module set for the use case
- setup and configuration
- custom adaptation or integration when needed
- maintenance, operations, and expansion support

Core sales message:

> We do not offer a generic self-serve product. We deliver modular project solutions shaped around customer needs.

## 4. Strongest Solution Areas Today

Based on the current codebase, the strongest solution areas are:

### Corporate websites and content operations

- `core`
- `pagebuilder`
- `media`
- `component_library`
- CMS delivery API

### Headless catalog and storefront foundation

- `product`
- CMS delivery
- `storefront-nextjs`

### Mail marketing and campaign operations

- `mail_marketing`
- tenant-based content and campaign management

### Reusable delivery foundation for agencies

- shared admin foundation
- tenant isolation
- reuse across multiple client projects

## 5. Positioning

Main message:

**"Modular project solutions tailored to customer needs."**

Support messages:

- reduces the risk of starting from scratch
- shortens delivery time
- provides tenant-safe architecture
- brings content, catalog, and operations onto one foundation

Language to use:

- modular
- customizable
- tenant-isolated
- reusable platform
- headless-ready

Language to avoid:

- self-serve product
- fixed subscription package
- one product for everyone

## 6. Pricing and Sales Model

Pricing is **project-based**. There is no fixed package pricing.

Pricing depends on:

- which modules are involved
- tenant and content structure complexity
- frontend or theme adaptation needs
- integration scope
- operations and support level

Sales flow:

1. discovery call
2. needs and scope clarification
3. recommended solution and module set
4. demo or proposal
5. setup and delivery
6. maintenance and expansion

## 7. Go-to-Market Priority

The first focus should not be a vague "platform" story. It should be clear solution stories:

- corporate website solution
- headless catalog / storefront solution
- tenant-based delivery foundation for agencies
- mail marketing operations solution

Primary channels:

- referrals and existing network
- LinkedIn outreach
- discovery call / demo request forms
- case studies and architecture-trust content

## 8. Success Metrics

Key metrics to track:

- number of qualified discovery calls
- proposal-to-project conversion rate
- average delivery time
- monthly operational revenue
- upsell / expansion rate
- module reuse rate

In short, Craftive's strategy is:

**not to sell SaaS, but to deliver modular project solutions on top of a reusable platform foundation.**
