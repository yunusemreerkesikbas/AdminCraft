# Sprint 17: Subdomain-Based Tenant Authentication

**Start Date:** 2025-10-20
**Effort:** 6-8 hours
**Dependencies:** Sprint 15, Sprint 16

---

## 🐛 Problem

Tenant admin login fails with **401 Unauthorized**.

**Root Cause:**

```
Frontend → POST /api/auth/login (no tenant identifier)
Backend → TenantContext not set → queries platform_management DB
Result → User not found → 401
```

**Why:** Tenant users exist in `ac_tenant_{id}.users`, not `platform_management.users`.

---

## ✅ Solution

**Subdomain-based tenant resolution:**

1. Frontend extracts subdomain from hostname
2. Frontend sends `X-Tenant-Subdomain` header
3. Backend resolves subdomain → tenantId
4. Backend sets TenantContext BEFORE UserRepository query
5. UserRepository queries correct tenant database

**URL Pattern:**

- SUPER_ADMIN: `http://admin.localhost:4200/sign-in`
- Tenant: `http://democompany.localhost:4200/sign-in`

**Routing Change:**

- OLD: `/tr/demo-company/project` (path-based)
- NEW: `/tr/project` (subdomain-based)

---

## 🛠️ Implementation

### Backend (3 files)

**1. AuthenticateCommand.java**

- Add `String subdomain` field

**2. AuthController.java**

- Read `@RequestHeader("X-Tenant-Subdomain") String subdomain`
- Pass to AuthenticateCommand

**3. AuthenticationServiceImpl.java**

```java
// Subdomain resolution logic
if (subdomain != null) {
    Tenant tenant = tenantRepository.findBySubdomain(subdomain);
    validate(tenant.isActive());

    // CRITICAL: Set context BEFORE UserRepository query
    tenantContext.setTenantId(tenant.getId());
    tenantContext.setTenantDbName(tenant.getDatabaseName());
}

// Now queries correct DB
User user = userRepository.findByEmail(email);
```

**Special handling:** `subdomain="admin"` → SUPER_ADMIN auth

### Frontend (4 files)

**1. sign-in.component.ts**

```typescript
extractSubdomainFromUrl(): string | null {
    const hostname = window.location.hostname;
    // democompany.localhost → "democompany"
    return hostname.split('.')[0];
}

signIn() {
    const subdomain = this.extractSubdomainFromUrl();
    this._authService.signIn({ ...form.value, subdomain });
}
```

**2. auth.service.ts**

- Add `subdomain` to credentials
- Send `X-Tenant-Subdomain` header

**3. app.config.ts**

- Add `APP_INITIALIZER`: Extract subdomain on startup

**4. app.routes.ts**

- Remove `tenantMatcher` (path-based tenant routing)
- Update routes: `/tr/project` (no tenant segment)

### API Changes

#### 1. Login Endpoint - New Headers

**Endpoint:** `POST /api/auth/login`

**Headers (Priority Order):**

```http
X-Tenant-Subdomain: democompany   # Priority 2 (new, recommended)
Content-Type: application/json
Accept-Language: tr               # Optional (default: "tr")
```

**Request Body:**

```json
{
  "email": "admin@democompany.com",
  "password": "admin123",
  "subdomain": "democompany"  // Optional (header takes priority)
}
```

**Response (Success 200):**

```json
{
  "result": "SUCCESS",
  "message": "auth.login.successful",
  "data": {
    "accessToken": "eyJhbGc...",
    "refreshToken": "eyJhbGc...",
    "tokenType": "Bearer",
    "expiresIn": 3600,
    "userId": 1,

    "fullName": "Admin User",
    "role": "TENANT_ADMIN",
    "preferredLanguage": "EN",

  }
}
```

**Response (Error 401):**

```json

  "result": "ERROR",

```

```
assets, auth, login, dashboard, console, portal
```

### Frontend Integration Checklist

**Required Changes:**

1. **Extract subdomain from hostname:**

   ```typescript
   const hostname = window.location.hostname; // e.g., "democompany.localhost"
   const subdomain = hostname.split('.')[0]; // "democompany"
   ```

2. **Send subdomain in login request:**

   ```typescript
   // Option A: Header (recommended)
   this.http.post('/api/auth/login', credentials, {
     headers: { 'X-Tenant-Subdomain': subdomain }
   });

   // Option B: Body (fallback)
   this.http.post('/api/auth/login', { ...credentials, subdomain });
   ```

3. **Handle subdomain in response:**

   ```typescript
   this.authService.signIn(credentials).subscribe(response => {

  const { subdomain } = response.data;
     // Store for future API calls
   });

   ```

4. **Update interceptor (if exists):**
   ```typescript
   // Add X-Tenant-Subdomain to all authenticated requests
   if (subdomain) {
     req = req.clone({
       setHeaders: { 'X-Tenant-Subdomain': subdomain }
     });
   }
   ```

### Security Notes for Frontend

⚠️ **IMPORTANT:**

1. **Always validate subdomain before sending:**
   - Pattern: `/^[a-z0-9](?:[a-z0-9-]{1,48}[a-z0-9])$/`
   - Min length: 3 characters
   - Max length: 50 characters

2. **Never trust user input:**
   - Backend validates all inputs
   - Frontend validation is UX, not security

3. **Generic error handling:**
   - Don't expose "Tenant not found" messages
   - Use generic "Invalid credentials" for all auth failures

4. **Case handling:**
   - Backend normalizes to lowercase
   - `DemoCompany` → `democompany` (automatic)

❌ **DON'T:**
