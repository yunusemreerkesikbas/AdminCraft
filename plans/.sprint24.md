# Sprint 24: Component Library Module

## <� Goal

Create a dynamic component management system for reusable UI components (header, footer, CTA, breadcrumb, etc.) with multi-language support.

---

## =� Module Structure

**Module:** `component_library`
**Dependencies:** `["core"]`
**Location:** Tenant-level (per-tenant database)

### Database Tables

```sql
-- Type definitions (header, footer, cta, etc.)
component_types (
  id, code, name, category, icon,
  extended_fields_schema JSON,  -- Optional dynamic fields
  is_system, created_at
)

-- Component items
components (
  id, uuid, uid, component_type_id, code, name,
  base_data JSON,      -- Standard fields (order, isVisible, styleClasses)
  extended_data JSON,  -- Type-specific fields
  status, created_at
)

-- Multi-language content (PageBuilder pattern)
component_i18n (
  id, uuid, uid, component_id, language,
  base_localized_data JSON,      -- Standard i18n (title, subtitle, description, links, button, image)
  extended_localized_data JSON,  -- Type-specific i18n fields
  status, published_at
)
```

### Seed Data

```sql
INSERT INTO component_types (code, name, category) VALUES
  ('header', 'Header', 'navigation'),
  ('footer', 'Footer', 'navigation');
```

## <� Architecture Decisions

### Base + Extended Fields Pattern

**Base Fields (All Components):**

- General: `order`, `isVisible`, `styleClasses`
- i18n: `title`, `subtitle`, `description`, `imageUrl`, `imageAlt`, `buttonText`, `buttonUrl`, `buttonStyle`, `links[]`

**Extended Fields (Optional, Type-Specific):**

- Defined in `component_types.extended_fields_schema`
- Created via admin UI (form-based or JSON import)
- Example: Header � `sticky: boolean`, Testimonial � `author: text, rating: number`

### Multi-Language (PageBuilder Pattern)

```
 Page/PageI18n pattern
 Tenant.supported_languages dynamic tabs
 API: GET/PUT /api/components/{id}/i18n/{lang}
 Publish per language
```

**API Endpoints (NEW):**
```
POST /api/components/types/validate-schema
Body: { "i18n": [{"key": "author", "type": "text", "label": "Author"}] }
Response: { "success": true, "data": {...} }
```

**Validation Rules:**
```
Max Fields: 20
Max Schema Size: 100KB
Key Pattern: ^[a-zA-Z][a-zA-Z0-9_]*$
Max Key Length: 50
Max Label Length: 100
Valid Types: text, textarea, number, boolean, select
XSS Sanitization: All labels and string values
```

**Field Type Constraints:**
- Text/Textarea: minLength, maxLength, pattern (regex)
- Number: min, max (with range validation)
- Select: options array (required, non-empty)
- Boolean: No type-specific constraints

**JSON Structure (Sprint 2):**
```json
extendedFieldsSchema: {
  "i18n": [
    {"key": "author", "type": "text", "label": "Author", "required": true, "maxLength": 100},
    {"key": "rating", "type": "number", "label": "Rating", "min": 1, "max": 5}
  ]
}
extendedData: {}
extendedLocalizedData: {"author": "John Doe", "rating": 5}
```
