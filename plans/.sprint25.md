## 📦 Response Format

```json
{
  "result": "SUCCESS",
  "data": {
    "uid": "footer-main",
    "type": "Footer",
    "category": "navigation",
    "title": "Footer Title",
    "isVisible": true,
    "styleClasses": "dark-theme",
    "entries": [
      {
        "uid": "cmsitem_36792026",
        "order": 0,
        "title": "Link 1",
        "isVisible": true,
        "customField1": "value1"
      }
    ]
  }
}
```

### Batch Response

```json
{
  "result": "SUCCESS",
  "data": {
    "data": { "uid1": {...}, "uid2": {...} },
    "meta": { "requested": 2, "found": 2, "notFound": [] }
  }
}
```

## ✅ Frontend (Completed)

### Files Created

| File                      | Location                  | Description                        |
| ------------------------- | ------------------------- | ---------------------------------- |
| `cms-delivery.service.ts` | `storefront/src/app/cms/` | Service (single + batch retrieval) |
| `cms-delivery.types.ts`   | `storefront/src/app/cms/` | TypeScript types                   |
| `index.ts`                | `storefront/src/app/cms/` | Barrel export                      |

### Endpoints Added

```typescript
// api-endpoints.ts
cmsComponent: 'cms/components/${uid}',
cmsComponentsBatch: 'cms/components'
```

### Service API

```typescript
import { CmsDeliveryService } from "@/app/cms";

// Single component
cms.getComponent("footer-main");
cms.getComponent("header", "EN");

// Batch (max 50)
cms.getComponents(["header", "footer", "sidebar"]);

// As Map
cms.getComponentsAsMap(["header", "footer"]);
```

### Usage in Component

```typescript
@Component({ selector: "app-footer" })
export class FooterComponent {
  protected cms = inject(CmsDeliveryService);
  protected footer$ = this.cms.getComponent("footer-main");
}
```

### Key Features

- Uses `ApiClientService.getPublic()` (no auth header)
- Uses `LanguageContextService` for default language
- Endpoint keys from `api-endpoints.ts`
