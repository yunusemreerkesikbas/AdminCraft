# Sprint 26: Content Slot & Page Template System

## 🎯 Goal

Enable Page-Component integration via Content Slots, following SAP Commerce Cloud patterns.

---

## ✅ Decisions

| Decision          | Choice            | Notes                                         |
| ----------------- | ----------------- | --------------------------------------------- |
| Slot naming       | Descriptive (SAP) | `Header`, `MainContent`, `Section1`, `Footer` |
| Component sharing | ✅ Yes            | Same component reusable across pages          |
| PageTemplate      | Phase 2           | Slots first, then template abstraction        |
| Slot restrictions | ❌ Skip           | Allow any component in any slot               |

---

## 📦 Phase 1: Content Slots

### Database Migration

#### V12\_\_page_slots.sql

```sql
CREATE TABLE page_slots (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    uid VARCHAR(50) NOT NULL UNIQUE,
    page_id BIGINT NOT NULL,
    slot_name VARCHAR(50) NOT NULL,
    position VARCHAR(20) NOT NULL,
    sort_order INT DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_page_slot (page_id, slot_name),
    FOREIGN KEY (page_id) REFERENCES pages(id) ON DELETE CASCADE
);

CREATE TABLE slot_components (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    slot_id BIGINT NOT NULL,
    component_id BIGINT NOT NULL,
    sort_order INT DEFAULT 0,
    is_visible BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    UNIQUE KEY uk_slot_component (slot_id, component_id),
    FOREIGN KEY (slot_id) REFERENCES page_slots(id) ON DELETE CASCADE,
    FOREIGN KEY (component_id) REFERENCES components(id) ON DELETE CASCADE
);
```

### Admin API Endpoints

| Endpoint                                                    | Method | Description   |
| ----------------------------------------------------------- | ------ | ------------- |
| `/api/pages/{id}/slots`                                     | GET    | List slots    |
| `/api/pages/{id}/slots`                                     | POST   | Create slot   |
| `/api/pages/{id}/slots/{slotName}`                          | DELETE | Delete slot   |
| `/api/pages/{id}/slots/{slotName}/components`               | POST   | Add component |
| `/api/pages/{id}/slots/{slotName}/components/{componentId}` | DELETE | Remove        |
| `/api/pages/{id}/slots/{slotName}/reorder`                  | PUT    | Reorder       |

### CMS Delivery API (Public)

```
GET /api/cms/pages/${uid}?lang=TR
GET /api/cms/pages?uids=uid1,uid2&lang=TR
```

**Frontend endpoints:**

```typescript
cmsPage: 'cms/pages/${uid}',
cmsPagesBatch: 'cms/pages'
```

**Response:**

```json
{
  "uid": "homepage",
  "slots": {
    "Header": [{ "uid": "header-main", "type": "Header", "title": "..." }],
    "MainContent": [{ "uid": "hero", "type": "HeroBanner", "title": "..." }]
  }
}
```
