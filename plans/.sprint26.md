# Sprint 26: Content Slot System

## 🎯 Goal

Enable Page-Component integration via Content Slots, following SAP Commerce Cloud patterns.

---

## ✅ Decisions

| Decision          | Choice             | Notes                                         |
| ----------------- | ------------------ | --------------------------------------------- |
| Slot naming       | Descriptive (SAP)  | `Header`, `MainContent`, `Section1`, `Footer` |
| Component sharing | ✅ Yes             | Same component reusable across pages          |
| PageTemplate      | Sprint 27          | Slots first, then template abstraction        |
| Slot restrictions | ❌ Skip            | Allow any component in any slot               |
| Shared slots      | `page_id = NULL`   | Global slots; use JPQL `IS NULL` for queries  |
| SEO fields        | ✅ Add to Page     | `robotTag` for meta robots directive          |
| Navigation nodes  | Sprint 28+         | Nested navigation tree (deferred)             |
| Restrictions      | Sprint 28+         | startDate/endDate visibility rules (deferred) |
| Response format   | Object-based slots | `slots: { "Header": [...] }` (not SAP nested) |

---

## 📦 Phase 1: Content Slots

### Database Migration

#### V12\_\_page_slots.sql

```sql
-- Shared slots have page_id = NULL (global slots like Header, Footer)
CREATE TABLE page_slots (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    uid VARCHAR(50) NOT NULL UNIQUE,
    page_id BIGINT NULL,                    -- NULL = shared/global slot
    slot_name VARCHAR(50) NOT NULL,
    position VARCHAR(20) NOT NULL,
    sort_order INT DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    is_shared BOOLEAN DEFAULT FALSE,        -- Explicit shared flag
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_page_slots_page (page_id),
    INDEX idx_page_slots_shared (is_shared),
    UNIQUE KEY uk_page_slot (page_id, slot_name),
    FOREIGN KEY (page_id) REFERENCES pages(id) ON DELETE CASCADE
);

CREATE TABLE slot_components (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    slot_id BIGINT NOT NULL,
    component_id BIGINT NOT NULL,
    sort_order INT DEFAULT 0,
    is_visible BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    UNIQUE KEY uk_slot_component (slot_id, component_id),
    FOREIGN KEY (slot_id) REFERENCES page_slots(id) ON DELETE CASCADE,
    FOREIGN KEY (component_id) REFERENCES components(id) ON DELETE CASCADE
);

-- SEO fields for Page entity
ALTER TABLE pages ADD COLUMN robot_tag VARCHAR(50) DEFAULT 'INDEX_FOLLOW';
ALTER TABLE pages ADD COLUMN template_uid VARCHAR(50) NULL;  -- Future: Sprint 27
```

### Component Picker Pattern

`ComponentListComponent` supports two modes:

```typescript
@Input() mode: 'admin' | 'picker' = 'admin';
@Output() componentSelected = new EventEmitter<ComponentDto>();
```

- **admin**: Full CRUD (edit, delete, create)
- **picker**: Select only (used in slot management)

Usage in `PageSlotListComponent`:

```typescript
this.#dialog.open(ComponentPickerDialogComponent, { ... });
dialogRef.afterClosed().subscribe(component => {
  if (component) this.#pageSlotService.addComponent(...);
});
```
