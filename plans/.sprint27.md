# Sprint 27: Page Template System

## 🎯 Goal

SAP Commerce Cloud-style Page Templates enabling reusable page layouts with predefined slot structures.

---

## ✅ Decisions

| Decision           | Choice      | Notes                                        |
| ------------------ | ----------- | -------------------------------------------- |
| Template naming    | Descriptive | `homepage-template`, `content-page-template` |
| Slot restrictions  | Optional    | `allowed_types` JSON field, NULL = all       |
| Auto slot creation | ✅ Yes      | Assign template → auto-create page_slots     |
| System templates   | ✅ Yes      | Pre-seeded, cannot be deleted                |

---

## 📦 Database Migration

### V13\_\_page_templates.sql

```sql
CREATE TABLE page_templates (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    uid VARCHAR(50) NOT NULL UNIQUE,
    name VARCHAR(100) NOT NULL,
    description VARCHAR(500) NULL,
    preview_image VARCHAR(500) NULL,
    is_system BOOLEAN DEFAULT FALSE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by BIGINT NULL,
    updated_by BIGINT NULL,

    UNIQUE KEY uk_page_template_uid (uid),
    INDEX idx_page_template_active (is_active)
);

CREATE TABLE template_slots (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    template_id BIGINT NOT NULL,
    slot_name VARCHAR(50) NOT NULL,
    position VARCHAR(20) NOT NULL,
    sort_order INT DEFAULT 0,
    is_required BOOLEAN DEFAULT FALSE,
    max_components INT NULL,
    allowed_types JSON NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    UNIQUE KEY uk_template_slot (template_id, slot_name),
    FOREIGN KEY (template_id) REFERENCES page_templates(id) ON DELETE CASCADE
);

-- Add template_id to pages
ALTER TABLE pages
ADD COLUMN template_id BIGINT NULL AFTER category_id,
ADD INDEX idx_page_template (template_id),
ADD CONSTRAINT fk_page_template
    FOREIGN KEY (template_id) REFERENCES page_templates(id) ON DELETE SET NULL;
```
