# Sprint 28: Unified Dialog System

## Scope

Standardized dialog components with base classes and shared UI.

## Implementation

### Base Classes (`@shared/components/`)

| Class                    | Purpose                                                 |
| ------------------------ | ------------------------------------------------------- |
| `SpaDialogBase`          | Core lifecycle (dialogRef, isSubmitting, cancel, close) |
| `SpaFormDialog`          | Form handling + mode (create/edit) + submit()           |
| `SpaLocalizedFormDialog` | Multi-language forms (generalForm + i18nForms)          |

### Shared UI Components (`@shared/components/spa-dialog/`)

| Component            | Usage                                |
| -------------------- | ------------------------------------ |
| `spa-dialog`         | Wrapper with header, content, footer |
| `spa-dialog-header`  | Title, subtitle, close button        |
| `spa-dialog-content` | Content area with type layouts       |
| `spa-dialog-footer`  | Cancel/Submit actions                |

**Content Types:** `form`, `tabbed`, `picker`, `container`

### Migrated Dialogs

- `PageSlotFormDialogComponent` → `SpaFormDialog`
- `PageSlotDialogComponent` → `SpaDialogBase`
- `ComponentPickerDialogComponent` → `SpaDialogBase`
- `EntryFieldDialogComponent` → `SpaFormDialog`
- `EntryFieldImportDialogComponent` → `SpaFormDialog`
- `ComponentTypeEditDialogComponent` → `SpaFormDialog`
- `ComponentEditDialogComponent` → `SpaLocalizedFormDialog`
- `ComponentEntryFormComponent` → `SpaLocalizedFormDialog`
