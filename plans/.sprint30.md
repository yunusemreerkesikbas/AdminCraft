# Sprint 30: Page-Template Admin UI Integration

## 🎯 Goal

Complete the Admin UI integration between Page and PageTemplate modules, enabling template selection during page creation/edit and automatic slot creation.

---

## ✅ Decisions

| Decision            | Choice            | Notes                                                 |
| ------------------- | ----------------- | ----------------------------------------------------- |
| Template assignment | Single API call   | `templateId` in `CreatePageRequest`, no separate call |
| Slot display        | Disabled readonly | Show slots in form as disabled list (not editable)    |
| Template change     | Replace slots     | Changing template replaces page slots with new ones   |

---

## 📋 Tasks

### Phase 1: Backend DTO Updates

- [ ] Add `templateId` to `PageDto`, `PageListDto`, `PageDetailDto`
- [ ] Add `templateId` to `CreatePageCommand`, `UpdatePageCommand`
- [ ] Update `PageServiceImpl.createPage()` to call `assignTemplateToPage()` if templateId provided
- [ ] Update `PageServiceImpl.updatePage()` to handle template change

### Phase 2: Frontend Type Updates

- [ ] Add `templateId?: number | null` to `page-builder.types.ts`
- [ ] Add `templateId` to `CreatePageFormData` and `EditPageFormData`
- [ ] Update `PageFormMapperService` to include `templateId`

### Phase 3: Form Schema & UI Updates

- [ ] Add template dropdown to create/edit page form
- [ ] Load active templates via `PageTemplateService.getActive()`
- [ ] Show disabled slot list when template selected (readonly, non-editable)

## 📖 Implementation Guide

### Backend

1. `PageCreateRequest.java` → Add `Long templateId`
2. `PageResponse.java`, `PageListResponse.java`, `PageDetailResponse.java` → Add `Long templateId` field + update `from()` method
3. `PageServiceImpl.java` → Set `page.setTemplateId(request.templateId())` in `createPage()` and `updatePage()`

### Frontend

1. `page-builder.types.ts` → Add `templateId?: number | null` to `PageDto`, `PageListDto`, `PageDetailDto`, `CreatePageRequest`, `UpdatePageRequest`
2. `page-form.types.ts` → Add `templateId?: number | null` to `CreatePageFormData`
3. `page-schema-builder.service.ts`:
   - Import `PageTemplate` from `../../templates/page-template.types`
   - Add `templates: PageTemplate[] = []` parameter to `buildPageCreateSchema()` and `buildPageEditSchema()`
   - Add `transformTemplateOptions()` method
   - Add template dropdown field at top of `#buildGeneralFields()`
4. `page-form-mapper.service.ts` → Add `templateId: (result as any).templateId ?? null` to both mapper methods
5. `page-list.component.ts`:
   - Inject `PageTemplateService`
   - Add `#cachedTemplates: PageTemplate[] = []`
   - Add `#loadTemplates()` method using `getActive()`
   - Pass templates to schema builder in `createPage()` and `editPage()`
   - Set `templateId` in initial form data

### Translations

Add to `admin.common.fields`:

- EN: `template: 'Template'`
- TR: `template: 'Şablon'`
