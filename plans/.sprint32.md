# Sprint 32: Navigation Node System

## Goal

Hierarchical Navigation Node system (SAP Commerce inspired) for mega menus: nested nodes + link entries.

## Scope

**In**

- Node tree CRUD (root + children)
- Node entries CRUD
- Reorder children under a parent
- CMS Delivery: fetch a nested tree by node uid
- DTO Refactoring: Move Request DTOs from Presentation to Application layer

**Out (Phase 2)**

- i18n tables and language-specific title / linkName

---

## Decisions

| Item           | Decision                                                            |
| -------------- | ------------------------------------------------------------------- |
| Module         | core (`backend/src/main/resources/db/tenant/core/`)                 |
| Migration      | V17 (global sequential: pagebuilder V16 is current highest)         |
| Identifiers    | Admin API uses `{id}` (numeric), CMS Delivery uses `{uid}` (string) |
| NodePosition   | LEFT, RIGHT, TOP, BOTTOM, CENTER                                    |
| AUTO_INCREMENT | 10000                                                               |
| Max Depth      | 5 levels (performance constraint)                                   |
| linkColor      | HEX format (#RRGGBB)                                                |
| i18n           | Phase 2                                                             |
| Architecture   | Clean Architecture (DTOs in Application Layer)                      |
| URL Security   | Only relative paths, http/https allowed (no javascript:, data:)     |
| Reorder        | Same-set semantics: request must contain exact existing items       |

## Database Migration

### `backend/src/main/resources/db/tenant/core/V17__navigation_nodes.sql`

```sql
CREATE TABLE navigation_nodes (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    uid VARCHAR(100) NOT NULL UNIQUE,
    title VARCHAR(200) NULL,
    parent_id BIGINT NULL,
    position VARCHAR(20) DEFAULT 'LEFT',
    sort_order INT DEFAULT 0,
    is_visible BOOLEAN DEFAULT TRUE,
    is_tab BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_nav_parent (parent_id),
    CONSTRAINT fk_nav_parent FOREIGN KEY (parent_id)
        REFERENCES navigation_nodes(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci AUTO_INCREMENT = 10000;

CREATE TABLE navigation_entries (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    uuid VARCHAR(36) NOT NULL UNIQUE,
    uid VARCHAR(100) NOT NULL UNIQUE,
    node_id BIGINT NOT NULL,
    item_type VARCHAR(30) NOT NULL,
    item_id VARCHAR(100) NULL,
    url VARCHAR(500) NULL,
    link_name VARCHAR(200) NOT NULL,
    link_color VARCHAR(30) NULL,
    target VARCHAR(20) DEFAULT '_self',
    is_external BOOLEAN DEFAULT FALSE,
    sort_order INT DEFAULT 0,
    is_visible BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_entry_node (node_id),
    CONSTRAINT fk_entry_node FOREIGN KEY (node_id)
        REFERENCES navigation_nodes(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci AUTO_INCREMENT = 10000;
```

## Rules (Bug Prevention)

| Rule                | Description                                                         |
| ------------------- | ------------------------------------------------------------------- |
| No cycles           | A node's `parent_id` cannot be itself or any of its descendants     |
| Max depth           | Maximum 5 levels of nesting                                         |
| Ordering            | Nodes and entries sorted by `sort_order ASC, id ASC`                |
| Visibility          | CMS delivery returns only `is_visible=true`                         |
| Entry validation    | URL type requires `url`; PAGE/COMPONENT requires `item_id`          |
| URL mutual exclus.  | URL type requires null `itemId`; others require null `url`          |
| URL security        | Only relative paths and http/https URLs allowed                     |
| Reorder same-set    | Request must contain exactly the existing child/entry IDs           |

## Sprint 32 Refactoring Summary

### 1. DTO Refactoring (Presentation → Application)

Deleted from `presentation/dto/request`:

- `CreateBlockRequest`, `CreateComponentEntryRequest`, `CreateEntryFieldRequest`
- `CreatePageRequest`, `CreatePageSlotRequest`, `CreatePageTemplateRequest`
- `CreateSectionRequest`, `CreateSiteRequest`, `CreateTemplateSlotRequest`
- `CreateTenantRequest`, `ReorderRequest`
- `UpdateBlockRequest`, `UpdateComponentEntryRequest`, `UpdatePageRequest`
- `UpdatePageTemplateRequest`, `UpdateSectionRequest`, `UpdateSiteRequest`
- `UpdateTenantRequest`

Created/Moved to `application/dto/request`:

- `PageCreateRequest.java`
- `PageI18nRequest.java`
- `PagePublishRequest.java`
- `TenantLanguagesUpdateRequest.java`
- `ReorderRequest.java` (Generic `<T>`)

### 2. Security Improvements

**URL Validation** (`NavigationServiceImpl.validateUrlAllowed`):

- Allows: relative paths, `http://`, `https://`
- Blocks: `javascript:`, `data:`, `vbscript:`

**TenantFilter Enhancement**:

- SUPER_ADMIN must provide tenant header for tenant-scoped endpoints
- Explicit path classification for security

### 3. Performance (N+1 Fix)

- `findSubtreeByRootId()` - Recursive CTE query
- `findSubtreeByRootUid()` - Recursive CTE query  
- `findByNodeIdIn()` - Batch entry loading
- In-memory tree construction

### 4. Reorder Logic

- Same-set validation (HashSet)
- Items re-indexed 0 to N-1
- Prevents partial updates and duplicates

### 5. i18n Keys Added
