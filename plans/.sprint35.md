### 3. CMS Delivery Flat Response (@JsonAnyGetter)

**Files:** `EntryDeliveryResponse.java`, `ComponentDeliveryResponse.java`, `ComponentDeliveryServiceImpl.java`, `PageDeliveryServiceImpl.java`

```java
// Before (toFlatMap manual conversion)
public record EntryDeliveryResponse(..., Map<String, Object> customFields) {
    public Map<String, Object> toFlatMap() { ... }
}

// After (@JsonAnyGetter - Jackson handles it)
@Getter @Builder
public class EntryDeliveryResponse {
    private String uid;
    @JsonIgnore
    private Map<String, Object> customFields;

    @JsonAnyGetter
    public Map<String, Object> getCustomFieldsFlat() {
        return customFields;
    }
}
```

**Result:** `{ "uid": "...", "imageUrl": "...", "linkUrl": "..." }` (flat, no nesting)
