# Sprint 38 - Server-Side Pagination, Sorting & Search

## Overview

Implemented a generic server-side pagination, sorting and search infrastructure for Admin modules.
Also implemented a **Fixed Pagination Footer** pattern across list views for consistent navigation.

public Page<Media> search(Pageable pageable, String searchQuery) {
    if (searchQuery == null || searchQuery.trim().length() < 2) {
        return mediaRepository.findAll(pageable);
    }
    return mediaRepository.searchByQuery(searchQuery.trim(), pageable);
}

### Frontend

**Types (`api.types.ts`):**

```typescript
export interface PageRequest {
  page?: number;
  size?: number;
  sort?: string;
}

export interface SearchRequest extends PageRequest {
  search?: string;
}
```

**CrudHttpService:**

```typescript
listPaged(request: SearchRequest): Observable<Page<T>> {
  return this.api.get<ApiResponse<Page<T>>>(
    this.endpoints.list,
    undefined,
    this.#buildQueryParams(request)
  ).pipe(map((response) => response.data));
}

#buildQueryParams(request: PageRequest | SearchRequest): Record<string, any> {
  const params: Record<string, any> = {};
  if (request.page != null) params.page = request.page;
  if (request.size != null) params.size = request.size;
  if (request.sort) params.sort = request.sort;
  if ('search' in request && request.search) params.search = request.search;
  return params;
}
```

**BasePaginatedListComponent:**

```typescript
// Debounced search with RxJS
readonly #searchInput$ = new Subject<string>();

ngOnInit(): void {
  this.#searchInput$.pipe(
    debounceTime(300),
    distinctUntilChanged(),
    takeUntil(this.destroy$)
  ).subscribe(query => {
    this.searchQuerySig.set(query);
    this.pageIndexSig.set(0);
    this.loadItems();
  });
}

onSearchInput(searchTerm: string): void {
  this.#searchInput$.next(searchTerm);
}

protected fetchItems() {
  const params: SearchRequest = {
    page: this.pageIndexSig(),
    size: this.pageSizeSig(),
    sort: this.sortCodeSig()
  };
  const query = this.searchQuerySig().trim();
  if (query.length >= this.minSearchChars) {
    params.search = query;
  }
  return this.service.listPaged(params);
}
```

### Navigation Module Integration

**Backend:**

- `NavigationController` standardized to return `ApiResponse<PageResponse<NavigationNodeResponse>>`.
- implemented `list()` method supporting `page`, `size`, `sort`, `search`.
- `SortableFieldsConfig` updated with navigation-specific sorts (`title`, `uid`, `sortOrder`).

**Backend:**

- Search performed on `name` and `description` (case-insensitive).
