# Sprint 40 - Product Module Implementation Plan

## Overview

Simplified Product Catalog module for AdminCraft, inspired by SAP Commerce Cloud (Hybris) Product module.

## Scope

### MVP (Phase 1)

| Feature                           | Description                                           |
| --------------------------------- | ----------------------------------------------------- |
| ProductType + AttributeDefinition | Dynamic field definitions (Component Library pattern) |
| Product + ProductI18n             | Product entity + multilingual content                 |
| ProductAttribute (EAV)            | Dynamic attribute values                              |
| Category (hierarchical)           | Parent-child category tree                            |
| Multi-category (N:N)              | Primary + secondary category support                  |
| Gallery (ProductMedia)            | Product gallery images                                |
| ResponsiveMediaSet                | Desktop/Mobile image support                          |
| Composite endpoints               | Atomic create/update (no separate i18n endpoints)     |
| CMS Delivery API                  | Public product/category API                           |
| PRODUCT_CATALOG module            | Tenant-based enable/disable                           |

### Out of Scope

| Feature            | Reason              |
| ------------------ | ------------------- |
| ImpEx              | Not required        |
| Solr               | Not required        |
| Catalog Versioning | Not required        |
| Stock Management   | Not required        |
| Variants           | Deferred to Phase 2 |

## Technical Decisions

| Topic                  | Decision                                                  |
| ---------------------- | --------------------------------------------------------- |
| **Field Types**        | TEXT, RICHTEXT, NUMBER, BOOLEAN, DATE, MEDIA              |
| **Status**             | DRAFT, PUBLISHED                                          |
| **Module**             | PRODUCT_CATALOG (tenant-based enable/disable)             |
| **CMS Filters**        | categoryUid, status=PUBLISHED, isVisible=true, pagination |
| **Admin Filters**      | search (name/sku), status, productTypeId, categoryId      |
| **Seed Data**          | General, Electronics, Clothing + sample attributes        |
| **Product Delete**     | Hard delete (CASCADE)                                     |
| **Category Delete**    | Prevent if has children (RESTRICT)                        |
| **ProductType Delete** | Prevent if has products (409 CONFLICT)                    |
| **Price Validation**   | @DecimalMin("0.0") on basePrice                           |
| **AUTO_INCREMENT**     | Start from 10000                                          |
| **i18n Strategy**      | Composite only (no separate i18n endpoints)               |
| **Publish Strategy**   | Product-level status (no per-language publish)            |

## API Endpoints

### Admin API (tenant-scoped, authenticated)

```
# Product Types
GET    /api/products/types                    (paginated + sort + search)
POST   /api/products/types
GET    /api/products/types/{id}
PUT    /api/products/types/{id}
DELETE /api/products/types/{id}

# Attribute Definitions
GET    /api/products/types/{typeId}/attributes
POST   /api/products/types/{typeId}/attributes
PUT    /api/products/types/{typeId}/attributes/{id}
DELETE /api/products/types/{typeId}/attributes/{id}

# Categories (composite only)
GET    /api/products/categories              (tree structure)
POST   /api/products/categories/composite    (category + i18n)
GET    /api/products/categories/{id}
GET    /api/products/categories/{id}/composite
PUT    /api/products/categories/{id}/composite
DELETE /api/products/categories/{id}

# Products (composite only)
GET    /api/products                         (paginated + sort + search + filters)
POST   /api/products/composite               (product + i18n + attributes + categories + media)
GET    /api/products/{id}
GET    /api/products/{id}/composite
PUT    /api/products/{id}/composite
DELETE /api/products/{id}
GET    /api/products/{id}/media              (gallery list)
POST   /api/products/{id}/media              (add media to gallery)
DELETE /api/products/{id}/media/{mediaId}    (remove from gallery)
```

### CMS Delivery API (tenant-scoped, unauthenticated)

```
GET    /api/cms/products                     (public product list)
GET    /api/cms/products/{uid}               (public product detail)
GET    /api/cms/categories                   (public category tree)
GET    /api/cms/categories/{uid}             (public category detail)
GET    /api/cms/categories/{uid}/products    (products in category)
```

## Database Migration

```sql
-- V30__product_baseline.sql

-- Product Types (start from 10000)
CREATE TABLE product_types (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(36) NOT NULL UNIQUE,
    code VARCHAR(50) NOT NULL UNIQUE,
    name VARCHAR(100) NOT NULL,
    category VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) AUTO_INCREMENT = 10000;

-- Attribute Definitions (start from 10000)
CREATE TABLE product_attribute_definitions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(36) NOT NULL UNIQUE,
    product_type_id BIGINT NOT NULL,
    code VARCHAR(50) NOT NULL,
    name VARCHAR(100) NOT NULL,
    field_type VARCHAR(30) NOT NULL,
    is_required BOOLEAN DEFAULT FALSE,
    is_searchable BOOLEAN DEFAULT FALSE,
    sort_order INT DEFAULT 0,
    validation_config JSON,
    FOREIGN KEY (product_type_id) REFERENCES product_types(id) ON DELETE CASCADE,
    UNIQUE KEY uk_attr_type_code (product_type_id, code)
) AUTO_INCREMENT = 10000;

-- Categories (start from 10000)
CREATE TABLE categories (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(36) NOT NULL UNIQUE,
    code VARCHAR(50) NOT NULL UNIQUE,
    parent_id BIGINT,
    sort_order INT DEFAULT 0,
    is_visible BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (parent_id) REFERENCES categories(id) ON DELETE RESTRICT,
    INDEX idx_category_parent (parent_id)
) AUTO_INCREMENT = 10000;

-- Category i18n (start from 10000)
CREATE TABLE category_i18n (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    category_id BIGINT NOT NULL,
    language VARCHAR(5) NOT NULL,
    name VARCHAR(200) NOT NULL,
    description TEXT,
    FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE CASCADE,
    UNIQUE KEY uk_category_lang (category_id, language)
) AUTO_INCREMENT = 10000;

-- Products (start from 10000)
CREATE TABLE products (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uid VARCHAR(36) NOT NULL UNIQUE,
    product_type_id BIGINT NOT NULL,
    sku VARCHAR(100) NOT NULL UNIQUE,
    base_price DECIMAL(15,2),
    currency VARCHAR(3) DEFAULT 'TRY',
    status VARCHAR(20) NOT NULL DEFAULT 'DRAFT',
    is_visible BOOLEAN DEFAULT TRUE,
    responsive_id BIGINT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (product_type_id) REFERENCES product_types(id),
    FOREIGN KEY (responsive_id) REFERENCES responsive_media_sets(id),
    INDEX idx_product_type (product_type_id),
    INDEX idx_product_status (status)
) AUTO_INCREMENT = 10000;

-- Product i18n (start from 10000)
CREATE TABLE product_i18n (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id BIGINT NOT NULL,
    language VARCHAR(5) NOT NULL,
    name VARCHAR(200) NOT NULL,
    short_description VARCHAR(500),
    description TEXT,
    seo_title VARCHAR(200),
    seo_description VARCHAR(500),
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    UNIQUE KEY uk_product_lang (product_id, language)
) AUTO_INCREMENT = 10000;

-- Product Attributes (start from 10000)
CREATE TABLE product_attributes (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id BIGINT NOT NULL,
    attribute_definition_id BIGINT NOT NULL,
    value_text TEXT,
    value_number DECIMAL(15,4),
    value_boolean BOOLEAN,
    value_date DATE,
    value_media_id BIGINT,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    FOREIGN KEY (attribute_definition_id) REFERENCES product_attribute_definitions(id),
    FOREIGN KEY (value_media_id) REFERENCES media(id),
    UNIQUE KEY uk_product_attr (product_id, attribute_definition_id)
) AUTO_INCREMENT = 10000;

-- Product-Category Links (composite key, no auto_increment)
CREATE TABLE product_category_links (
    product_id BIGINT NOT NULL,
    category_id BIGINT NOT NULL,
    is_primary BOOLEAN DEFAULT FALSE,
    sort_order INT DEFAULT 0,
    PRIMARY KEY (product_id, category_id),
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE CASCADE
);

-- Product Media/Gallery (start from 10000)
CREATE TABLE product_media (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id BIGINT NOT NULL,
    media_id BIGINT NOT NULL,
    media_type VARCHAR(30) DEFAULT 'GALLERY',
    sort_order INT DEFAULT 0,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE,
    FOREIGN KEY (media_id) REFERENCES media(id),
    UNIQUE KEY uk_product_media (product_id, media_id)
) AUTO_INCREMENT = 10000;
```

## Notes

- Follows Component Library pattern (type-driven, dynamic attributes)
- Integration with existing Media module (ResponsiveMediaSet, gallery)
- Composite endpoints only (no separate i18n endpoints)
- Product-level status (no per-language publish)
- Hard delete (CASCADE)
- Category delete: prevent if has children (RESTRICT)
- ProductType delete: prevent if has products (409 CONFLICT via BusinessRuleViolationException)
- Repository impls use @Transactional on save/delete methods
- ProductMedia.mediaType uses ProductMediaType enum (PRIMARY, GALLERY, THUMBNAIL)
